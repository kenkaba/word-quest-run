## 1. キャラクター設定書

### 名前

**LUMI / ルミ**（語源: lumen = 光の単位）

- 2音節・全言語で発音可能・商標的に短い → 世界展開に適する
- 「言葉の光を集める者」という世界観の核と直結する

### 立ち位置

かつて世界は言葉でできていた。言葉が失われ、道は途切れた。
ルミは**失われた言葉を拾い集め、道を架け直しながら走る**唯一の魔法使い。

- 戦士ではない。**踏破者**である
- 敵を憎まない。道を塞ぐものを「越える」だけ
- 立ち止まらない。振り返らない。**だから常に後ろ姿**

### 性格

好奇心が恐怖より強い / 口数は少ない / 知らない言葉を見つけると足が速くなる /
失敗しても数秒で立ち上がる（プレイヤーの再挑戦意欲と同期させる）

### 年齢感

14〜16歳相当。幼くしすぎない（幼いと「冒険したくなる格好良さ」が死ぬ）。

### デザインの一行

**「とんがり帽子の先が折れた、片側だけ長い三つ編みの、大きなブーツの魔法使い」**

この一行で他の誰とも間違えないこと。それが達成できていなければ設計失敗。

## 2. 正面 / 背面 / 側面（ターンアラウンド仕様）

頭身: **4.5頭身**（頭=1、全高=4.5）。可愛さと走行の躍動を両立する下限。
基準全高 **900px**（制作解像度）。頭部高 200px。

| 部位 | 全高比 | 900px時 |
|---|---:|---:|
| 帽子の先端〜頭頂 | 18% | 162px |
| 頭頂〜顎 | 22% | 200px |
| 顎〜肩 | 5% | 45px |
| 肩〜ウエスト | 16% | 144px |
| ウエスト〜膝 | 19% | 171px |
| 膝〜靴底 | 20% | 180px |
| 靴の高さのみ | 9% | 81px |

### 正面

- 顔は**やや俯き**（走る前の集中）。目は大きく、瞳に光の粒
- 左胸に言葉袋（サッチェル）のストラップが斜めに走る
- 杖は右手。体の右前で軽く握る

### 背面（ゲーム内の主表示）

- **左肩から背中へ長い三つ編みが1本**。右側は肩までの遊び毛
- **右肩にだけハーフマント**（左肩は出ている）→ 非対称が背面でも効く
- 帽子の先は**左後方へ折れる**
- 背中にサッチェル（言葉袋）。走ると軽く跳ねる
- スカーフが右へ流れる

### 側面

- 帽子の折れが最も分かる角度。折れ角 **約35度**
- 三つ編みは体の外側へ弧を描く
- 前傾 **8度**（走行時は15度）

## 3. 配色設計

**全ステージで不変**。世界の色が変わっても本人は変わらない＝識別性の核。

| 部位 | 色 | HEX | 役割 |
|---|---|---|---|
| 帽子・ハーフマント | 深紫 | `#5B3A9E` | 主色。世界の中で最も彩度の高い紫 |
| 帽子の裏地・マント裏 | 濃紫 | `#2F1C5C` | 陰。立体を作る |
| 髪（根） | 金 | `#FFD98F` | 副主色 |
| 髪（毛先） | 淡金 | `#FFF0C4` | 先端を明るくして風を見せる |
| ローブ | 温白 | `#FDF6FF` | 明度の逃げ場。背景から抜く |
| 差し色・金具・杖の光 | 琥珀 | `#FFD76A` | 魔法と重要点にのみ使う |

| 肌 | 温肌 | `#F7D9A8` | — |

## 4. シルエット案（採用案と不採用案）

シルエットテスト = **黒一色に潰して、誰か分かるか**。

### 採用: 案C「折れ帽と片三つ編み」

```
     ◣           帽子の先が左へ折れる（唯一無二の頂点）
    ▟█▙          広いつば（左が下がる非対称）
     █           細い首
   ▟███▖         右肩だけマントの膨らみ
  ▐ ███ ▌        左に三つ編みが垂れる
    ███          くびれ（ベルト）
   ▟█████▖       スカートの広がり
    ██ ██        脚
   ▄██▄▄██▄      大きなブーツ（低重心）
```

**成立理由**
1. 頂点が非対称に折れる → 上部だけで判別できる
2. 左に三つ編み・右にマント → 左右で違うシルエット＝どの角度でも情報がある
3. 上（尖）→中（くびれ）→下（重い塊）の3拍子でリズムがある
4. ブーツが大きい＝小さく表示しても足元が消えない

### 不採用

- **案A「左右対称の正統派魔女」**: 美しいが没個性。シルエットテストで他と混ざる
- **案B「大きなローブで全身を覆う」**: 布の塊になり、走行の脚が読めない（Ver3.0の失敗の再来）
- **案D「露出の多い装備」**: 世界展開で年齢レーティングと文化的許容の問題を招く。却下

## 7. 走行アニメーション仕様

基準 **12fps 相当のキーポーズ**（実装は連続補間）。1サイクル = 2歩。

| # | キー | 位相 | 内容 |
|---:|---|---|---|
| 1 | 接地(左) | 0° | 左足が地面を捉える。体は最も低い。土煙発生。膝は軽く曲がり衝撃を吸収 |
| 2 | 通過 | 90° | 支持脚が伸び、遊脚の膝が最も高い。体は最も高い |
| 3 | 蹴り出し | 135° | 支持脚が後方へ伸びきる。靴底が見える |
| 4 | 空中 | 180° | 両足が地面から離れる。体はわずかに前傾 |
| 5〜8 | 右側で反復 | 180〜360° | 左右反転 |

### 必須の物理表現

- **フォロースルー**: 髪・三つ編み・マント・スカーフは本体を**2〜4フレーム遅れて**追う
- **位相差**: 三つ編み3節・スカーフ3節はそれぞれ**さらに1フレームずつ遅らせる**（波を作る）
- **スカッシュ&ストレッチ**: 接地で縦95%横105%、空中で縦105%横97%
- **体幹の逆回転**: 肩と腰が逆位相で±4度
- **前傾**: 走行時15度、加速時20度

### ポーズ別仕様

| ポーズ | 内容 |
|---|---|
| 走行 | 上記サイクル |
| ジャンプ | 溜め（沈む3フレーム）→ 伸び上がり → 空中で脚を畳む → 着地で沈む |
| 着地 | 縦85%まで潰れ、土煙、カメラ沈み込み6px、2フレーム停止（ヒットストップ） |
| 横移動 | 体を進行方向へ12度傾け、三つ編みとマントは逆方向へ流れる |
| 失敗 | 前のめり／尻もち／壁激突の3種。帽子が一瞬浮いて遅れて落ちる（コミカルさで再挑戦を促す） |
| 待機 | 呼吸で±2px、スカーフだけ揺れる |
