# WORD QUEST RUN — 5ステージ 世界設計書

最終更新: 2026-07-28 / 担当スキル: `world-art-director`

**色違いにしない。** 建築・自然・天候・光・障害物・音・感情まで別世界として設計する。
検収基準: 各ステージのスクリーンショットを並べて「別のゲームに見える」こと。

共通の背骨は `docs/ART_BIBLE.md`（形言語＝丸い塊＋鋭い結晶／空気遠近／光源の一貫性）。

## 進行の物語構造

失われた言葉を拾いながら、**地上 → 森 → 水 → 極夜 → 天空**へ登っていく。
高度が上がるほど空が広くなり、世界は human から divine へ移る。

| # | ステージ | 距離 | 高度感 | 感情 |
|---:|---|---|---|---|
| 1 | 暁の浮遊遺跡 | 0m〜 | 地上 | 出発・懐かしさ |
| 2 | 翡翠の魔法森 | 300m〜 | 森の底 | 発見・生命 |
| 3 | 星霜の大滝 | 600m〜 | 崖の中腹 | 畏怖・速度 |

## 1. 暁の浮遊遺跡

**一行**: 夜明けの光が、崩れた石の柱を金色に染める。

| 項目 | 設計 |
|---|---|
| 建築 | 角の欠けた石柱・崩れたアーチ・浮遊する石段。直線と鋭角（結晶側） |
| 自然 | 乾いた大地・低い岩・わずかな苔。植物は少ない |
| 天候 | 快晴の夜明け。風は弱い |
| 光 | **右上から低い角度**の朝日。長い影が道を横切る |
| 空 | 紫→桃→橙の4段。星が западに残る。層状の雲 |
| 障害物 | 崩れた足場（跳ぶ）・倒れた柱（滑る）・石の門（すり抜け） |
| 道 | 石畳。目地が光る。ところどころ欠けている |
| 粒子 | 金色の塵がゆっくり舞う |
| 音 | 遠い風・石の軋み |
| 固有ギミック | 道の脇に**浮遊する石段**が上下し、通過時に視差で高度感を出す |

## 2. 翡翠の魔法森

**一行**: 巨木の天蓋から、光の筋が降りてくる。

| 項目 | 設計 |
|---|---|
| 建築 | 木に飲まれた祠・蔓の絡んだ石碑。人工物は自然に負けている |
| 自然 | **巨木・丸い樹冠・発光する下草・キノコ**。丸い塊が支配的 |
| 天候 | 湿潤。薄い霧が地表を這う |
| 光 | **左上から**。天蓋越しの木漏れ日。地面に光の斑点 |
| 空 | ほとんど見えない。樹冠の隙間から翠と白 |
| 障害物 | 垂れ下がる蔓（潜る）・太い根（跳ぶ）・落ちた大枝（回避） |
| 道 | 苔むした土。根が横切る |
| 粒子 | 胞子・光る羽虫・落ち葉 |
| 音 | 葉擦れ・水滴・遠い鳥 |
| 固有ギミック | **木漏れ日が動く**。正解の道に光が差す瞬間がある |

## 3. 星霜の大滝

**一行**: 崖の縁を、水音だけが支配する。

| 項目 | 設計 |
|---|---|
| 建築 | 崖に打ち込まれた桟道・鎖・水車の残骸。細く危うい |
| 自然 | **巨大な滝**・濡れた岩・霧。垂直の線が支配的 |
| 天候 | 常時の水しぶき。虹が架かる |
| 光 | **右上から**。水面と濡れた岩の反射でハイライトが多い |
| 空 | 蒼と白。滝の霧で下半分が霞む |
| 障害物 | 途切れた桟道（跳ぶ）・落水（すり抜け）・滑る岩（バランス） |
| 道 | 濡れた木の桟道。反射する |
| 粒子 | 水しぶき・虹の粒 |
| 音 | 轟音。他ステージより音圧が高い |
| 固有ギミック | **虹**が距離に応じて架かる。100コンボ時は虹が二重になる |

## 4. オーロラ雪嶺

**一行**: 音が消える。空だけが動いている。

| 項目 | 設計 |
|---|---|
| 建築 | 氷に埋もれた標柱・凍った吊り橋。ほぼ人工物が無い |
| 自然 | **雪の稜線・氷の結晶・氷柱**。鋭い結晶が支配的 |
| 天候 | 無風の極夜。時折の細雪 |
| 光 | **左上から弱い月光**＋**オーロラの下からの照り返し**（唯一、下からの光がある） |
| 空 | 濃紺。**オーロラが3層**でうねる。星が最も多い |
| 障害物 | 氷の裂け目（跳ぶ）・氷柱（回避）・雪庇（崩れる） |
| 道 | 圧雪。足跡が残る（**唯一、通過の痕跡が残るステージ**） |
| 粒子 | 細雪・凍る息 |
| 音 | ほぼ無音。足音だけが響く |
| 固有ギミック | **足跡が道に残る**。振り返らないキャラだが、プレイヤーには軌跡が見える |

## 5. 天空神殿

**一行**: 雲の上に、まだ言葉が残っている。

| 項目 | 設計 |
|---|---|
| 建築 | **無傷の巨大神殿**・黄金の列柱・浮遊する祭壇。唯一、崩れていない |
| 自然 | 雲海のみ。地面は建築だけ |
| 天候 | 静穏。雲が足元を流れる |
| 光 | **右上から強い金**。列柱の間に明確な光の帯 |
| 空 | 金→橙→紫。太陽が最も大きい |
| 障害物 | 開閉する門（タイミング）・浮遊する足場（跳ぶ）・光の壁（正解でのみ消える） |
| 道 | 磨かれた石。反射して空を映す |
| 粒子 | 金の光片・舞い上がる羽根 |
| 音 | 合唱のような残響 |
| 固有ギミック | **雲が足元を流れる**ため高度が体感できる。到達＝ゲームの報酬そのもの |

## ステージ遷移の演出

切替時に **1.2秒の閃光 + 地名表示 + 音の切替**。
「次の景色を見たい」を報酬にするため、遷移は必ず**上へ登る**方向で演出する。

## 実装状態（2026-07-28）

| 要素 | 状態 |
|---|---|
| 空・光源方向・パレット | ✅ 実装済み（手続き描画） |
| 遠景/中景/脇の props | ⚠️ 各ステージ1種のみ。設計上は3種必要 |

| 障害物 | ❌ 未実装（正解/失敗の演出で代替中） |
| 音 | ❌ 合成音のみ。ステージ固有BGMなし |

**次の実装優先度**: 固有ギミック > 脇 props の3種化 > 天候 > 障害物 > 音
