## 1. 世界観

**「忘れられた言葉が眠る、光の遺跡世界」**

かつて世界は「言葉」でできていた。言葉が失われたとき世界は分断され、道は途切れた。
主人公は言葉を選び直すことで**道を再生しながら**走る。だから正解すると道が架かり、失敗すると道が崩れる。

- 時代感: 文明が滅びたあとの静けさ + 魔法技術の残光。廃墟だが不気味ではなく、**美しく穏やか**。
- 感情のトーン: 冒険 > 恐怖。孤独だが希望がある。
- 「戦う」より「進む」。敵は障害であって憎悪の対象ではない。

## 2. 魔法体系

- 魔法は**光と結晶**として現れる。炎・血・爆発は使わない。
- 主人公の魔法色は**琥珀（アンバー）**。世界の遺物は各ステージの発光色。
- 正解 = 世界が主人公に応える（道が架かる・光が走る）
- 失敗 = 世界が閉じる（光が消える・道が崩れる）。痛みではなく**喪失**として描く。

## 3. 形言語（Shape Language）

**「丸みのある塊 + 鋭い結晶」** の二元。混ぜない。

| 分類 | 形 | 例 |
|---|---|---|
| 有機物・生命 | 丸い塊、やわらかい曲線 | 主人公、木、丘、雲 |
| 魔法・遺物・人工物 | 鋭い結晶、直線と鋭角 | 遺跡の柱、浮遊島の縁、答えの板、魔獣の角 |

主人公は「丸い塊」側。だから世界の鋭さの中で**目立つ**。

## 4. 光の規則（非交渉）

1. ステージごとに**光源方向 `sunX`（-1=左 .. +1=右）と光源色**を1つだけ定義する。
2. すべてのオブジェクトは光源側が明るく、逆側が暗い。
3. 逆光側の縁に**リムライト**を必ず置く（シルエットを立てる）。
4. 地面には**接地影**（接地点ほど濃く小さい）。
5. 発光は意味のあるものだけ（正解・選択中・主人公の魔法・重要CTA）。

## 5. 空気遠近（奥行きの正体・最重要）

深度 `z`（0=手前 .. 1=地平）に対し、**すべての描画色**へ次を適用する。例外を作らない。

```
hazeAmount(z) = 0.85 * z^1.35
finalColor = mix(baseColor, hazeColor, hazeAmount)
```

- `hazeColor` はステージの空の地平色
- 同時に**彩度とコントラストも落ちる**（霞色へ寄ることで自動的に達成）
- 適用漏れがあると、その要素だけ「貼り付けた図形」に見える

層構成は4層: **最遠景（山）→ 遠景（浮遊島・大建築）→ 中景（並木・柱）→ 前景（脇を流れる props）**。層ごとにスクロール速度を変える。

## 6. カラーパレット（1ステージ = 主色2 + 差し色1 + 発光色1）

| ステージ | 距離 | 主色1（空） | 主色2（地） | 差し色 | 発光色 | 光源 |
|---|---|---|---|---|---|---|
| 暁の浮遊遺跡 | 0m | `#f2a97e` 暁 | `#3c2f5c` 紫影 | `#7d5fa8` | `#ffd9a0` | 右上 (+0.55) |
| 翡翠の魔法森 | 300m | `#8fe3c4` 翠 | `#163d33` 深緑 | `#2f7a63` | `#b6ffcf` | 左上 (-0.5) |
| 星霜の大滝 | 600m | `#a9d4ff` 蒼 | `#1b2a4a` 紺 | `#3d5a8c` | `#dff0ff` | 右上 (+0.4) |
| オーロラ雪嶺 | 1000m | `#1a3358` 夜 | `#2b3d55` 雪影 | `#4a648a` | `#eaf6ff` | 左上 (-0.6) |
| 天空神殿 | 1500m | `#ffcf95` 金 | `#4a3550` 紫石 | `#8a6a9c` | `#ffe9b0` | 右上 (+0.5) |

**この4色から派生しない色相を足さない。**

## 7. 建築・自然

- 建築: 遺跡の柱、崩れたアーチ、浮遊する石段。**鋭い結晶**側。直線と鋭角、上部が欠けている。
- 自然: 丸い樹冠、なだらかな丘、層状の雲。**丸い塊**側。
- 浮遊島: 上面は平ら、下面は逆円錐に尖る（結晶側）。縁が発光色で光る。

## 8. 空

- 4段グラデーション（天頂→上空→地平上→地平）。
- 地平近くに**霞の帯**（空気遠近の受け皿）。
- 光源（太陽/月）は画面内に置き、ブルームを持つ。
- 夜系ステージのみ星とオーロラ。

## 9. キャラクター（主人公）

詳細モーションは `character-motion-camera-director` スキルを参照。造形の固定要素:

- 魔法使いの少女。**常に後ろ姿**、必ず画面奥へ。
- 頭身: 約4.5頭身（可愛さと走行の躍動を両立）
- 帽子: とんがり帽子（先がしなる）。**シルエットの決め手**。
- 髪: 長い金髪。3つの毛束に分かれ、それぞれ別位相で揺れる。
- マント: 紫。本体より遅れて追従。
- 杖: 右手。先端がアンバーに発光し粒子を曳く。
- 配色: 帽子とマント=紫 `#6f4bb0` / 髪=金 `#ffd98f` / ローブ=白 `#fdf6ff` / 魔法=琥珀 `#ffd76a`

**この配色は全ステージで不変**（世界の色が変わっても主人公は同じ）。これが識別性を作る。

## 10. 敵（魔獣）

- 「丸い塊 + 鋭い角」。体は丸く、角と爪だけが結晶的に鋭い。
- 色はステージの影色。**発光する目**だけが差し色。
- 憎悪の対象ではなく「道を塞ぐ存在」。倒すと霧散する（血・破壊表現なし）。

## 11. 障害物

崩れた足場 / 塞ぐ石壁 / 結晶のトゲ / 途切れた橋。すべて「道の再生」の文脈で説明できること。

## 12. 装備（将来）

帽子 / マント / 杖 / 髪飾り / 靴。**シルエットが変わるもの**を優先（色替えだけの装備は作らない）。

## 13. UI

- ガラス/結晶調。半透明 + 内側ハイライト + 角丸 + 細い縁。
- 不透明な四角パネル禁止。
- 問題文は箱に入れず、光る文字として空に浮かべる。
- 答えは板 + **道へ降りる光の柱**で対応を示す。

## 14. エフェクト

| 用途 | 表現 | 色 |
|---|---|---|
| 主人公の魔法 | 杖先の粒子・軌跡 | 琥珀 |
| 正解 | 光の橋・光条・粒子の拡散 | 翠 `#7dffa8` |
| 失敗 | 光の消失・崩落・砂塵 | 朱 `#ff6a6a`（短時間のみ） |
| 環境 | 浮遊する光粒・葉・雪 | ステージ発光色（低輝度） |
| コンボ | オーラ → 覚醒 → 虹 | 琥珀 → 金 → 虹 |

**環境エフェクトは必ず UI と主人公より暗く**。視線を奪わせない。
