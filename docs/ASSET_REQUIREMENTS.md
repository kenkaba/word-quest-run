# 正式アート素材 要求仕様 — WORD QUEST RUN

現在の描画は**すべて手続き的（Canvas図形＋グラデーション＋照明計算）**で、正式なラスターアートは1枚も使っていない。
図形で無理に代用して「完成」とは扱わない方針のため、真の商用品質に到達するために必要な素材をここに明示する。

この環境では画像生成ツールが使えないため、素材の制作は外部（浅井の手配または画像生成サービス）が必要。
**金銭が発生する場合は着手前に浅井へ確認する。**

---

## 1. 主人公（最優先）

パーツ分割2D＋ボーン風アニメーション（採用方式B）で使う。

| パーツ | サイズ(px) | 透過 | 用途 |
|---|---|---|---|
| 帽子（つば・冠部・先端） | 320×240 | 必須 | 先端がしなる。3分割で別々に揺らす |
| 頭（後頭部） | 220×220 | 必須 | 髪の下に隠れる部分を含む |
| 髪（毛束A/B/C） | 各 200×420 | 必須 | 3束を別位相で揺らす。根元が回転軸 |
| マント（本体・裏地） | 420×460 | 必須 | 裾が波打つ。裏地は別レイヤー |
| 上体（ローブ） | 240×260 | 必須 | ベルトは別パーツ推奨 |
| 腕（上腕・前腕）×2 | 各 120×180 | 必須 | 肘で分割 |
| 脚（腿・脛）×2 | 各 130×190 | 必須 | 膝で分割 |
| ブーツ×2 | 各 150×170 | 必須 | 靴底が見える角度も |
| 杖（柄・先端） | 120×520 | 必須 | 先端は発光レイヤーを別に |

- 全パーツ共通: 回転軸（ピボット）を仕様書に明記すること
- 光源: 右上／左上の2バリエーション、または法線マップ相当の陰影レイヤー
- 配色は `docs/ART_BIBLE.md` 第9節に従う（帽子/マント=紫・髪=金・ローブ=白・魔法=琥珀）

## 2. 背景（ステージごと・全5ステージ）

| レイヤー | サイズ | 透過 | 備考 |
|---|---|---|---|
| 空（グラデーション＋雲） | 1200×900 | 不要 | 横タイル不要。ステージごと |
| 最遠景（山・大建築） | 2400×600 | 必須 | 横シームレスタイル |
| 遠景（浮遊島・神殿・大滝） | 2400×700 | 必須 | 横シームレスタイル |
| 中景（並木・柱） | 2400×800 | 必須 | 横シームレスタイル |
| 路面テクスチャ | 512×512 | 不要 | 縦シームレス。石畳/苔/雪/溶岩 |
| 脇の prop（各ステージ3種） | 各 400×600 | 必須 | 遺跡柱・樹木・水晶・神殿柱・岩 |

- ガラス板のフレーム（9スライス）: 96×96、透過必須
