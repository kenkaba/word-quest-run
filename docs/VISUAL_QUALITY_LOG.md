## 2026-07-28 — Visual Intelligence System 導入 / Ver3.1 ビジュアル再構築

### 撮影した場面

タイトル / 通常走行 / 3択出題中 / 正解演出 / 失敗演出 / 高コンボ(14・16) / ボス / 結果画面
解像度: 375px・390px・430px。連続フレームで位相差も確認。

### 実装前に特定した「幼稚に見える」原因（症状→原因）

| 症状 | 実際の原因 |
|---|---|
| 背景が図形の集合 | 全要素が同一の彩度・コントラスト。奥行きによる減衰が皆無 |
| 空気感が無い | 空気遠近が地平の帯だけ。山・木・道・脇の props に未適用 |
| 光と影が平坦 | 光源方向が未定義。単色 or 縦グラデのみで陰影・接地影が無い |
| キャラが記号 | 脚が直線2本で膝が無い。髪とマントが本体と同位相＝布に見えない |
| 走行感が弱い | 上下 bob のみ。接地の証拠（土煙・影の濃縮・カメラ沈み）が無い |
| モーションが機械的 | すべての揺れが同じ sin 波。位相差・遅延・減衰が無い |
| 質感が無い | ベタ塗り。粒状感・面分割・微細な明度差が無い |

### 実装した対策

1. **空気遠近を全描画要素へ適用**（`depth(color, z)`）— 奥ほど霞色へ寄り彩度が落ちる。4層構成。
2. **光源モデル** — ステージごとに `sunX` を定義。明面/暗面/リムライト/接地影。
3. **キャラクター再構築** — 膝のある2節の脚（順運動学）、フォロースルー（遅延バッファで髪・マントが本体を遅れて追う）、接地時の土煙、ベルト・裾の金縁・ブーツ折返し、リムライト。
4. **カメラ** — 足元を画面高72%へ引き上げ（沈み込み解消）、速度でFOV変化、着地の沈み込み、横移動の追従遅延。
5. **質感** — 路面と地面の流れる帯、フィルムグレイン、split-tone カラーグレーディング、ビネット再設計。
6. **魔獣の再設計** — 「丸い塊＋鋭い結晶の角」、瘴気、発光する目、リムライト。

### 発見・修正した実バグ

- **`roundRect` のパス融合**（重大）: native の `roundRect` は `beginPath` しないため、光の柱と答えの板が1つのパスとして塗られ、板が塗り潰されて文字が消えた。さらに polyfill（古いSafari）は `beginPath` するため**ブラウザ間で描画が変わる**状態だった。全11箇所を `rrect()` ヘルパーへ統一し、回帰テストを追加。
- カメラ初期値が未同期で起動直後に画面端へ黒帯が出る → `camX/lagX` を `charX` に一致させ、移動量をオーバースキャン内へクランプ。
- 霧の上端が硬い直線で、ボスと遠景を「切った」ように見せていた → 多段グラデーションへ。
- 脚の運動学が逆で遊脚の足が下がっていた（膝の曲げ不足）→ 実測して修正（遊脚22.3 / 蹴り抜き26.7 / 接地33.1）。
- 主人公の髪とマントが広すぎて体と脚を覆い「三角コーン」に見えていた → 幅と丈を詰め、脚を露出。

### 自動テスト

**45 / 45 PASS**（ビジュアル関連の新規回帰テストを含む）
- 空気遠近が深度に対し単調増加 / 地平で85%
- 全ステージに光源方向と霞色が定義されている
- 主人公が画面下へ沈まない（足元 68〜75%）
- 速度で遠近が深まり、基準速度で戻る
- 布・髪が本体を遅れて追う（フォロースルー）
- 脚が関節する（遊脚の足が支持脚より上がる／支持脚が接地を登録）
- `rrect` が必ず新しいパスを開始する（図形融合の再発防止）
- 起動直後にカメラが乖離しない（画面端の黒帯防止）

### 性能

- **1.30 ms/フレーム**（375×812・DPR2＝実キャンバス 750×1624、粒子85〜98個、グレイン・グレーディング込み）
- 10倍遅い端末でも 13ms ≒ 75fps 相当。モバイル性能の要件を満たす。

## 2026-07-29 — 商品完成度監査（実プレイ中心）

**評価方法**: 機能テストではなく実プレイ。起動→通常走行→5/10コンボ→ゲージ50/25/10%→時間切れ→
左中央右の選択→正解→不正解→ボス→結果→リトライを実機幅で撮影し、連続フレームで動きを確認した。

### 90点に到達するために必要なこと

いずれも手続き描画の限界を超えるため、`docs/ASSET_REQUIREMENTS.md` の正式アートが前提。

1. **正解/失敗の見せ場を「文字」から「動き」へ**（+2〜3点見込み: 項目7・8）
   光の橋が実際に架かる、壁を走る、崖から落ちる、といったスプライトアニメーション。
2. **主人公の原画差し替え**（+2点見込み: 項目2）
   パーツ分割19点。小さく表示しても人物として読める描き込み。
3. **決定的な一枚の演出**（+1〜2点見込み: 項目10）
   画面いっぱいの魔法、ボス撃破のカットイン。
