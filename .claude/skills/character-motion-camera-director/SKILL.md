# Character / Motion / Camera Director

## 主人公の非交渉ルール

- 魔法使いの美少女。**常に後ろ姿**で、**必ず画面奥へ**走る（手前に向かって走らせない）
- 頭身・シルエット・髪・帽子・マント・杖が**シルエットだけで判別できる**
- 足が地面を蹴っているのが分かる（接地の瞬間に土煙と接地影）
- 髪・マント・スカート・装飾は速度に応じて揺れる
- 走行 / ジャンプ / 着地 / 回避 / 失敗でポーズを分ける
- **上下移動だけで走行を表現しない**

## 走行サイクル（機械的にしないための必須要素）

1. **膝を曲げる**：脚は直線2本ではなく、腿と脛の2節。前脚は膝を上げ、後脚は蹴り抜く。
2. **重心の上下**：接地の瞬間に最も低く、蹴り出しで最も高い（sin波の位相を脚と合わせる）。
3. **体幹の逆回転**：肩と腰が逆位相でわずかに回る。
4. **フォロースルー（追従遅れ）**：髪・マント・裾は本体の動きを**遅れて**追う。バネ or 遅延バッファで実装し、本体と同位相にしない。
5. **スカッシュ&ストレッチ**：跳躍で縦に伸び、着地で横に潰れる。
6. **接地の証拠**：足が着いた瞬間だけ土煙・影の濃縮・わずかなカメラ沈み込み。

## カメラの非交渉ルール

- 進行方向が広く見える（空を大きく、地平は画面の40〜50%）
- **キャラクターを画面最下部へ沈めない**。全身と足元が見える位置（画面高の 68〜75% 付近に足元）
- 速度による画角（FOV）変化：速いほど遠近を強める
- 着地時の衝撃（カメラの短い沈み込み）
- 緩い上下動（呼吸のような bob）
- 横移動時の**追従遅延**（カメラはキャラの横移動を遅れて追う。剛体追従にしない）
- パララックス（層ごとに異なる速度）
- 奥行きによるスケール変化
- 演出時だけスロー・ズーム・回り込み（常用しない）

## 実装チェック

- 1フレーム静止画で「走っている」と分かるか（脚の角度差・土煙・なびき）
- 髪とマントが本体と**同じ位相で**動いていないか（同位相なら追従遅れが無い＝機械的）
- 足元が画面外・UI外に出ていないか
- 高速時と低速時でスクリーンショットを比べて、遠近と流れの差が見えるか

## 完了条件

連続フレームを撮って、脚・髪・マント・土煙が別々の位相で動いていることを目視確認できること。
