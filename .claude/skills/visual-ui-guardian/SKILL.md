# Visual UI Guardian

## 絶対に守る視線設計

プレイ中、プレイヤーの目線は**画面中央の狭い帯**に留まること。

```
問題（画面中央より少し上）
   ↓
3本の道（＝答え）
   ↓
主人公
```

この3つが**1回の視線移動で認識できる**縦一直線に並ぶ。

## 具体規則

- **問題表示**：画面中央より少し上（画面高の 17〜24%）。最上部にも最下部にも置かない。
- **回答**：別ボタンにしない。**3本の道へ直接**結びつける（板を置く場合は光の柱などで道と対応させる）。
- **キャラクター**：画面下に沈みすぎない。UIや結果表示を隠さない。
- **HUD**：距離・コンボ・ライフ**のみ**。背景世界を壊す四角いパネルを乱用しない（ガラス/結晶調で世界へ馴染ませる）。
- **可読性 > 演出**：発光・光条・フラッシュで文字のコントラストを落とさない。

## 自動検証（実装済みの回帰テスト）

`?selftest=1` に以下が含まれていること。壊したら必ず直す。

- 答えの板が**重ならない**（最長の日本語訳 × 複数解像度）
- 答えの板が**画面外に出ない**
- ボス等の大型要素が**答えと問題文を覆わない**
- 空が画面の40%以上（ローアングル維持）
- レーンの左中右が常に L < C < R の順で道幅内

## 目視チェック

- 375 / 390 / 430px で横スクロールが出ないか
- 最も派手な瞬間（高コンボ＋ボス＋演出）でも3択が読めるか
- 失敗フラッシュ中に「正解: 〇〇」が読めるか

## 完了条件

最も情報量が多い瞬間のスクリーンショットで、問題・3択・主人公がすべて判読できること。
