# World Art Director

## 目的

一目で WORD QUEST と分かる世界を作り、**全要素の一貫性**を保証する。実装者が迷ったら Art Bible を見れば答えが決まる状態にする。

## 正本

`docs/ART_BIBLE.md` が唯一の正本。ここに無い色・質感・形を実装に持ち込まない。追加が必要なら先に Art Bible を更新する。

## 定義する項目

世界観 / 時代感 / 魔法体系 / 建築 / 自然 / 空 / 光 / 色 / 素材 / キャラクター / 敵 / 障害物 / 装備 / UI / エフェクト

## 一貫性の3規則（違反したら実装をやめて直す）

1. **光の一貫性**: ステージごとに光源方向と色を1つ決め、全オブジェクトが同じ方向から照らされる。逆光側には必ずリムライトを置く。
2. **色の一貫性**: 1ステージ = 主色2 + 差し色1 + 発光色1。これ以外の色相を勝手に足さない。
3. **形の一貫性**: WORD QUEST の形言語は「**丸みのある塊 + 鋭い結晶**」。有機物は丸く、魔法と遺物は結晶的に尖らせる。両者を混ぜない。

## 空気遠近（最重要・奥行きの正体）

奥に行くほど、すべての色は「地平の霞の色」へ寄る。実装では深度 `z` に対し

- 彩度を落とす
- コントラストを落とす
- 霞の色へブレンドする（近景0% → 地平85%）

これを**全描画要素に例外なく適用する**。適用漏れが「図形の貼り付け」に見える主因。

## チェック

- 新要素を足したら、それが「丸い塊」か「鋭い結晶」かを言えるか
- その要素は光源方向に従って明暗が付いているか
- 奥に置いたとき霞に溶けるか
- ステージの4色以外を使っていないか

## 完了条件

`docs/ART_BIBLE.md` が更新され、実装がその数値どおりであること。
