# WORD QUEST RUN

3つの道を選んで走る、**英単語ランニングアドベンチャー**。

走りながら、画面中央の英単語の意味に合う道（左・中央・右）を選び、どこまでも走り続けるスマホ向けゲーム。勉強画面ではなく、遊んでいるうちに英単語を覚える体験を目指しています。

- **視線は常に画面中央の1か所**：主人公・英単語・3本の道を同じ視線範囲に配置
- **主人公後方視点の疑似3Dランナー**：Canvasによる軽量表現（重い3Dは使わない）
- **インストール不要 / オフライン対応**：Service Worker でキャッシュ
- **スマホ最適化**：iPhone Safari を含むモバイル縦画面向け、safe-area 対応

## 遊び方

1. 画面中央に英単語が表示される
2. 3本の道に日本語の意味が1つずつ表示される
3. 正しい意味の道を選ぶ
4. 正解ならそのまま走り抜け、距離がのびる
5. まちがえるとライフが1つ減る（0でゲームオーバー）
6. 連続正解でスピードアップ。ボスも登場

### 操作

| | 左 | 中央 | 右 |
|---|---|---|---|
| タップ | 画面左1/3 | 画面中央1/3 | 画面右1/3 |
| スワイプ | ← | ↑ | → |
| キーボード(PC) | ← | ↑ | → |

タップだけでも完全に遊べます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面（HTML/CSS）とエントリポイント |
| `game.js` | ゲームエンジン（疑似3Dランナー、出題、演出、入力、ボス、ヒント、結果） |
| `words.js` | 単語データ `window.WORDS`（**ここに追記するだけで単語を増やせる**） |
| `sw.js` | Service Worker（オフライン対応・キャッシュバージョン管理） |

### 単語の追加方法

`words.js` の配列へ次の形式で追加するだけです。

```js
{ w: "英単語", p: "/発音/", a: "正しい日本語訳", x: ["誤答1", "誤答2", "誤答3"], d: 1, e: "例文" }
```

`d` は難易度：`1`=初級 / `2`=中級 / `3`=上級 / `4`=MASTER。

## ローカルで遊ぶ / テスト

```bash
python3 -m http.server 8000
```

- 通常プレイ： <http://localhost:8000>
- 自己テスト： <http://localhost:8000/?selftest=1>（左下にPASS/FAILバッジ、コンソールに詳細）

## デプロイ

静的ファイルのみ。Netlify などにこのフォルダをそのまま公開できます。Service Worker のキャッシュ名（`sw.js` の `CACHE`）は Ver 更新のたびに上げてください（古いキャッシュは自動削除されます）。
