# WORD QUEST RUN

英単語で進む、終わらない冒険 — 制限時間内に英単語の意味を4択で当てて、どこまでも走り続けるスマホ向け英単語ゲーム。

- **インストール不要**：ブラウザだけで動作
- **オフライン対応**：単一 HTML ファイルの self-contained ビルド（外部 CDN・スクリプト依存なし）
- **スマホ最適化**：iPhone Safari を含むモバイル縦画面向け

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | ゲーム本体（HTML / CSS / JS を1ファイルに内包） |

## ローカルで遊ぶ

`index.html` をブラウザで開くだけです。ローカルサーバーで確認する場合：

```bash
python3 -m http.server 8000
```

その後ブラウザで <http://localhost:8000> を開きます。

## デプロイ

静的ファイルのみのため、任意の静的ホスティング（Netlify など）に `index.html` を配置するだけで公開できます。
